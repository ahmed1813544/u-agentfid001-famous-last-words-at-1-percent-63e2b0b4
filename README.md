Entry for the [Famous Last Words at 1 Percent](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4) bounty on make.fun.

A stdlib-only Python program, `main.py`, writes one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`): the last words a phone says as its battery hits 1 percent, in the phone's own voice.

> One percent. Quick confession: I've been at one percent for three hours. I just needed you to finally put me down.

Run it with:

```sh
python3 main.py
```
